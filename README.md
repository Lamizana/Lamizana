## Projets phares

### [ZehdBox](https://github.com/Lamizana/ZehdBox)
Site vitrine & base de connaissances personnelle — portfolio, cours Python, fiches projets, blog technique. Déployé avec **MkDocs + GitHub Actions**.

### [ft_transcendance](https://github.com/Lamizana/ft_transcendance)
Projet final du tronc commun 42 — application web **Pong multijoueur** (Django, PostgreSQL, Docker, Nginx, HTML5 Canvas).

### [Tokeniser](https://github.com/Lamizana/Tokeniser)
Création d'un token **BEP-20 (GOLD42)** déployé sur la BNB Smart Chain Testnet (Solidity, OpenZeppelin).

### [Dashboard-population-France](https://github.com/Lamizana/Dashboard-population-France)
Dashboard **Streamlit** analysant les données publiques de `data.gouv.fr` (population, violences faites aux femmes).

### [Minishell](https://github.com/Lamizana/Minishell)
Interpréteur de commandes simple, similaire à bash, en **C** avec libft et readline.

### [ft_irc](https://github.com/Lamizana/ft_irc)
Serveur **IRC en C++98** (RFC 1459), multi-clients, modes de canaux, gestion par `select()` + bonus Pierre-Papier-Ciseaux.
